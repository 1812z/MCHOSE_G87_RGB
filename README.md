# 迈从 G87 Artemis 灯光插件

## 介绍

通过 **2.4 GHz 无线接收器**控制迈从 G87 的 87 键灯光，适配设备 `41E4:2001`，适用于 Windows x64。

- 已按实际键盘校准 87 键映射，支持 Artemis 灯效同步。
- 支持 **0–100% 连续亮度**及 **1–30 FPS** 调节，默认 **9 FPS**，设置自动保存。
- 静态颜色每秒重发，避免 GIF 模式空闲熄灭。
- 为控制无线传输量，每帧最多合并为 6 组颜色，渐变效果会有所简化。

## 使用教程

1. 安装并运行 [Artemis](https://artemis-rgb.com/)，连接 G87 的无线接收器，将键盘切换到 **2.4G 模式**。
2. 从系统托盘彻底退出 **MCHOSE HUB**，关闭正在运行的键盘校准工具。
3. 在 Artemis 的 **设置 → 插件** 中导入 `Artemis.Plugins.MchoseG87-0.5.0.0.zip`，启用 **MCHOSE G87 Wireless**。
4. 在设备布局中摆放 G87，应用覆盖键盘的 Profile。
5. 打开插件配置，调节亮度和 FPS；建议先使用默认 **9 FPS**。

更新插件后若仍显示旧布局，禁用再启用插件，或重启 Artemis。若显示不全或闪烁，可降低 FPS，并确认 MCHOSE HUB 和校准工具已退出。
